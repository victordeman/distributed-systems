# Lab 1: Sockets & Threads

In this lab, you will build a multi-threaded echo server using Python's `socket` and `threading` modules.

## Starter Code
You can find the starter code in the [GitHub repository](https://github.com/victordeman/distributed-systems).

## Objectives
- Understand TCP socket programming in Python.
- Implement a basic server that can handle multiple concurrent clients.
- Handle partial failures and connection resets gracefully.
